This guide details how I configured my laptop in order to work with [Terraform](https://developer.hashicorp.com/terraform)

In order to create Terraform scripts in VSCode it is recommended to use the following extension which provides recommendations, syntax highlighting, and info-on-hover:

- [HashiCorp.terraform](https://marketplace.visualstudio.com/items?itemName=HashiCorp.terraform)

The extension requires the following packages to be installed:

```sh
brew tap hashicorp/tap
brew install hashicorp/tap/terraform
```
